# Emoji Rush

**One file.** Open [`index.html`](index.html) in a mobile browser or desktop Chrome.

## What’s inside
- Splash → main menu → character select → 60s blitz rounds → results
- 12 characters with unlocks, rarities, and unique powers
- Match-3 / specials / Blitz Meter / hero spells
- Coins, high score, and settings saved in `localStorage`
- Synthesized SFX + optional chiptune bed (Web Audio — no asset files)

No install. No build. No other files required.
