# CROSSY HOP Retention Library

Organized soft-currency retention data & helpers. **No real-money IAP.**

| Module | Role |
|--------|------|
| `tips.js` | Endless tip / idle copy bank |
| `death-flavor.js` | Death screen flavor variants |
| `missions.js` | Daily/weekly mission templates |
| `loot-curves.js` | Payout & pity weight tables |
| `seasons.js` | FOMO season catalog |
| `achievements.js` | Meta achievement tree |
| `callouts.js` | Combo / near-miss / claim lines |
| `catalog-pad.js` | FOMO labels, star drip, login pouches, heat tables |
| `balance.js` | Score→difficulty drip curve |
| `hooks.js` | Runtime pickers + `window.HOP_RETENTION` |
| `index.js` | Barrel export |

Import from the game via `./retention/hooks.js` (or `index.js`).
